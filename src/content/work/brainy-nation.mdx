## The opportunity

Brainy Nation needed a content-managed website that could serve visitors in
English and Arabic. Both versions had to communicate the same brand and
information while respecting the very different reading directions.

## The approach

The project used WordPress and structured custom fields so the internal team
could maintain programme content without changing templates.

Arabic required more than translated copy. Layout direction, component order,
alignment, navigation, and visual details all needed to mirror appropriately
from left to right into a coherent right-to-left interface.

<ProjectNote title="Designed in both directions">
	The English interface was never treated as the universal default. Each
	component was considered as part of both reading experiences.
</ProjectNote>

## Contribution

- Developed the responsive WordPress theme and structured content fields.
- Implemented English and Arabic language variants.
- Adapted navigation, layout, and components for right-to-left reading.
- Created reusable content modules for the Brainy Nation team.
